# PLP Python Week 4 Assignment

## File Descriptions
* `welcome.py`: Contains a function that simplifies repetitive welcoming messages using a single parameter.
* `toolbox.py`: A collection of three utility functions demonstrating basic arithmetic, comparison logic, and default parameter values.

## Reflection
The hardest function to write was `greet` because it required understanding how default parameters work when an argument is missing versus when it is explicitly provided. Managing the string concatenation with the optional greeting, comma, and punctuation also required careful attention to match the exact output format.
